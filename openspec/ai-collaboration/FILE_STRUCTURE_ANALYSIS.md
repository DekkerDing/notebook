```markdown
## AI协作配置

> **激活条件**: 当项目存在 `openspec/ai-collaboration/AGENTS.md` 时启用

### 首次对话规则

在**新对话开始时**，必须先读取：
1. `openspec/ai-collaboration/AGENTS.md` - 了解项目规则
2. 根据任务类型，读取对应的规范文件

### 执行规则

- **静默执行**: 读取规则时直接执行，无需向用户汇报
- **仅读一次**: 同一轮对话中，已读过的文件无需重复读取
- **规范优先**: 项目规范优先于通用最佳实践
```
